# mushy v0.1.2

Uninstall mushy with one command, keeping your local linked files and recovery history:

```sh
curl -fsSL https://github.com/sudhanshug16/mushy-links/releases/latest/download/uninstall.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://github.com/sudhanshug16/mushy-links/releases/latest/download/uninstall.ps1 | iex
```

- Removes login startup, waits for syncing to stop, removes mushy's marked shell setup, and deletes only its three executables.
- Preserves linked files, sync state, history, saved SSH passwords, profile backups, and unrelated files in the installation directory.
- Supports custom installation paths and profiles, and older installations using a temporary checksum-verified cleanup helper.
- Adds `mushy shell uninstall` and `mushy daemon uninstall` for removing components separately.
- Adds uninstall instructions to the README and reference, with native CI coverage on Linux, macOS, and Windows.

Run `mushy auth forget HOST` before uninstalling if you also want to remove a saved SSH password. Other devices keep their links.
