Soft links across devices, with a simpler setup.

Install on both devices with one line:

```sh
curl -fsSL https://github.com/sudhanshug16/mushy-links/releases/latest/download/install.sh | sh
```

Then open a new terminal and link your remote files:

```sh
ln -m devbox:~/notes ./notes
```

- The installer chooses the correct release, checks its checksum, installs all helpers, and configures the shell without administrator privileges.
- Bash, Zsh, Fish, and PowerShell gain `ln -m`. Ordinary `ln` commands retain native behavior. Existing profile content is preserved and backed up.
- Windows has its own one-line PowerShell installer: `irm https://github.com/sudhanshug16/mushy-links/releases/latest/download/install.ps1 | iex`.
- Linux ARM64 binaries are now included. Linux x64 and ARM64 builds support glibc 2.35 and newer.
- The README now starts with installation and linking; advanced behavior is in the reference included in the archives.

Mushy keeps local copies and synchronizes changes over SSH, including file deletions. Files work offline, and sync resumes after reconnecting. Both devices need mushy; receiving devices must accept SSH connections. Use ordinary SSH once to verify access and trust the host key before linking.

All five native builds are gated by CI. Tests include shell dispatch and native `ln` passthrough, real installer upgrades, checksum rejection, OS secure credential stores, login startup, and Linux SSH mesh integration. Windows binaries include the C runtime. macOS binaries are not Developer ID signed or notarized. Other filesystem and recovery restrictions are documented in the reference.
