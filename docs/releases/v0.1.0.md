First release of mushy, an SSH-based automatic file synchronization CLI.

- Local copies synchronize edits and deletions in both directions, including through device chains and meshes.
- Concurrent edits converge deterministically using the original modification time; recoverable losing content is retained.
- Regular files, folders, and inside-root relative symlinks are supported.
- Workload, metadata, and recovery limits bound resource use. Unexpired recovery content is preserved when storage fills.
- Login startup, offline retries, pause/resume, history, restoration, and unlink/export are included.
- SSH keys/agents and passwords stored in Linux Secret Service, macOS Keychain, or Windows Credential Manager are supported.
- Root replacement protection is implemented on Unix and Windows.

Downloads include `mushy`, `mushy-askpass`, and `mushy-background`. Install all three together and add their directory to PATH on both peers. OpenSSH is required; receiving peers must accept SSH connections. See the included README for setup and commands.

Builds are provided for Linux x86_64 (Ubuntu 24.04), macOS Apple Silicon and Intel, and Windows x86_64. `SHA256SUMS` lists archive checksums. macOS binaries are not Developer ID signed or notarized.

All release builds are gated by native CI, including secure credential stores and startup registration. Linux additionally runs a real OpenSSH mesh integration test. Windows groups containing symlinks require Developer Mode or symlink privileges.

Known limits: structural file/directory conflicts require manual intervention; external applications can race final filesystem replacement; transfers send whole files. Ownership, ACLs, extended attributes, distributed locks, and transactional database synchronization are not supported. See the README for portability restrictions and recovery behavior.
